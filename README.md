## 线路：普通国际出口是什么水平

这是决定 RackNerd 能不能用的关键，也是各类推荐文章最容易含糊过去的地方。

按第三方实测口径，洛杉矶普通 163 骨干线路白天延迟 150–170ms，晚高峰会涨到 220ms，丢包 1%–5%。CN2 GIA 线路在同样时段是 145–165ms，丢包基本低于 0.5%。RackNerd 的表现比普通 163 骨干的平均水平还要松一些：电信 150–190ms，联通和移动 190–250ms，晚高峰丢包最高到 12%。

12% 的丢包意味着什么？SSH 会卡顿，网页会转圈，文件传输会中断重试。它不是“打不开”，而是“能用但难受”。如果你的访问者主要在北美或欧洲，这段中美线路的抖动跟他们没关系；如果你的用户全在国内，这就是硬伤，加钱也解决不了，因为 RackNerd 不提供 CN2 GIA 产品线。

## 年付促销价不等于长期价，按三年算一遍

年付 $21.99 是首年（或当前批次）的价格。RackNerd 的特价套餐不定期更换，2025 年底还是 $11.11 起，现在翻了一倍，这已经说明了问题：**促销价不是长期锁定的价格**。

行业里存在几种不同的计费模式，直接决定你三年下来花多少：

- 部分商家承诺“续费同价”，原价本身不变，优惠只作用于首年；
- 部分商家给“循环折扣”，每次续费都打折；
- RackNerd 这类特价套餐属于按批次定价，续费金额在结账页的循环计费栏里显示。

下单时多看一栏：结账页会写明这次是首期金额还是循环金额。用 2 到 3 年的总价做比较，再决定值不值。年付 $21.99 的机器，就算第二年涨到 $30，三年总支出也在 $80 以内，仍然便宜；真正要警惕的是把它当长期基础设施，结果第三年发现续费价接近翻倍。

## 按场景给结论

**海外建站、外贸独立站。** 合适。客户在北美的话，洛杉矶或纽约机房，2GB 特价 $35.99/年起步，装宝塔加 WordPress 够用，5TB 月流量对日均几千 PV 的站点绰绰有余。记得自己配好 SSL 和异地备份。

**国内访问为主。** 不合适。这条线路给不了国内用户稳定体验，晚高峰 12% 的丢包不是优化能救的。真要做国内访问，预算得提到年付 $35.99–39.99 档才有 CN2 GIA 或三网优化线路，再往上到 $169.99 档才谈得上晚高峰稳定。

**备份、监控探针、轻量服务。** 非常合适，这也是 RackNerd 最舒服的定位。1GB 特价 $21.99/年，3TB 月流量，拿来存异地备份、跑 Uptime 监控、挂个小 API，延迟和丢包都不影响它干活。

**练手、CI/CD、开发测试。** 合适。KVM 虚拟化，SolusVM 面板可以自助重装系统，2GB 档跑 Docker 和 GitHub Actions runner 都够。用完不续费也不心疼，反正本来就不退款。

**要大带宽独立服务器。** 这是另一个品类，别拿 VPS 的价格去预期。美国大带宽独服按月起卖，BGP 1000M 不限流量的入门配置大约 $89/月，10G 端口的高配方案在 $239 到 $1,499/月之间。VPS 是年付几十美元，独服是月付三位数，量级差了一个数量级，需求不同就别放一起比。
